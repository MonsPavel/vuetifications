# Проверка улучшений 1.8

Ветка: `feat/v1.8-improvements`, база: `main` / `9cfbc95` (1.7.0).
Архитектурные изменения v2 не перенесены.

## Состав

- `closeOnClick` и `pauseOnHover` выключены по умолчанию.
- Причины паузы hover/focus независимы; переход на кнопку закрытия не снимает паузу.
- Уведомление с отрицательной длительностью можно закрыть.
- Встроенные SVG наследуют цвет. Геометрия извлечена из оригинальных SVG 1.7;
  существующие URL в сторе и пользовательские изображения сохранены.
- Анонсы проходят через очередь, одинаковые сообщения разделяются очисткой live-region.
  Таймер очереди отменяется при размонтировании.
- Release вызывается из CI после unit/lint/build, Storybook и security-scan.
  Сборка использует проверенный SHA; устаревшие коммиты пропускаются.

## Проверки

- RED: `npm test -- src/__tests__/improvements.test.ts` — 12 падающих, 4 проходящих теста до реализации.
- GREEN: `npm test` — 80/80 unit-тестов.
- `npm run lint` — ESLint и vue-tsc проходят.
- `npm run test:coverage` — строки/инструкции 99.06%, ветви 96.19%, функции 96.15%; пороги 80% пройдены.
- `npm run test:storybook` — 4/4 сценария Chromium: обычное закрытие, closeOnClick,
  отрицательная длительность, hover + focus с реальными таймерами и анимациями.
- `npm run build` — ESM и UMD собираются; публичные notify/remove/clear доступны.
- UMD smoke: рендер, currentColor и handle на Vue 3.2.0 и 3.4.0 проходят.
- Текущая версия Vue в окружении: 3.5.21.

- YAML CI/release разобран через js-yaml, связи jobs и checkout проверенного SHA проверены.
- Production audit: после точечного обновления postcss/nanoid — 0 уязвимостей.
  Полный audit dev-зависимостей всё ещё сообщает 46 находок; массовое обновление toolchain
  не включено в эту ветку. Релизный коммит теперь сохраняет и обновлённый package-lock.json.

## Границы проверки

- Vue 3.0.0: отсутствует runtime-хелпер createElementVNode. Ошибка воспроизведена
  как на ветке 1.8, так и на исходном main, собранном тем же toolchain. Это старое
  несоответствие peer range; повышение минимальной версии не включено в minor.
- Реальные скринридеры не запускались: тесты подтверждают изменения DOM, а не завершение речи.
- Storybook a11y остаётся в режиме todo; взаимодействия проверяются, нарушения a11y
  пока не блокируют CI. Предупреждения об отсутствующих MDX, markdown-to-jsx и decodeEntities — от toolchain; сценарии проходят.
- GitHub workflows проверены локально по конфигурации; удалённый CI и публикация не запускались.
- Номер пакета остаётся 1.7.0 до semantic-release. Для minor нужен feat-коммит,
  без BREAKING CHANGE; при squash следует сохранить conventional-заголовок.
